# 明細取込

銀行通帳・カード利用明細をファイルで取り込み、既存の仕訳と突合して、未照合の行から仕訳伝票を一括起票する機能です。取り込んだ明細は、[銀行元帳](ledger.md#銀行元帳)の入出金履歴と突合されます。

## できること

| 取込元 | 形式 | 入口 | 処理 |
|---|---|---|---|
| 銀行通帳 | Excel(.xlsx)/CSV/画像 | 銀行元帳 →「明細取込」 | 既存仕訳と突合 → 未照合行を一括起票 |
| 社用カード明細 | PDF（Web明細の印刷） | 銀行元帳 →「明細取込」 | 利用行ごとに経費起票（貸方=未払金カード） |
| 個人カード明細 | Excel/CSV/画像/PDF | 精算書入力 →「カード明細から取込」 | チェックした行を精算書の明細に追加 |

## 取り込みの流れ

1. 「取り込む」で種別・口座（またはカード名）とファイルを指定します
2. 内容確認でパース結果（行数・期間・警告）を表示します。銀行系は残高整合（前残+入金-出金=次残）を検証し、崩れがあれば警告します
3. 「取り込む」で明細が登録されます

## 突合と起票（銀行通帳）

1. 「既存仕訳と突合」ボタンで、取り込んだ口座の仕訳明細と照合します
   * 金額が一致し、伝票日付が明細日の前後3日以内の明細を対応付けます
2. 未照合の行は「起票用 支払先」を選んで「一括起票」します
   * 借方=支払先マッピングの科目、貸方=取り込んだ口座の伝票が、日付ごとに作成されます（承認待ち）
   * 消費税は科目の税区分から自動導出されます（経費精算と同じルール）
3. **利息行は自動でテンプレ仕訳になります**:
   * 借方 普通預金（税引後） + 借方 源泉所得税 / 貸方 受取利息（税抜）
   * 明細が税引後のみの表記でも、源泉徴収率(15.315%)から税抜額を逆算します
   * 源泉額が丸め0円になる極小額の利息は「借方 普通預金 / 貸方 受取利息」のみです
4. 対象外にしたい行は「対象外にする」で除外できます

## 社用カード明細（PDF）

カードWeb明細の印刷PDFを取り込むと、利用行ごとに経費起票します。

* 借方=支払先マッピング（利用店名からの候補提示）、貸方=未払金（カード）
* 取り込んだPDF本体は「明細取込」の記録に保持され、画面から参照できます
* 銀行側の引落行（摘要にカード名を含む行）は、カード明細の支払総額・支払日と照合したうえで、「借方 未払金 / 貸方 普通預金」の決済伝票を起票します

## 個人カードの立替精算

立替払いで個人カードを使った場合、精算対象は明細の一部（メモ等で印を付けた行）です。

1. 精算書入力画面の「カード明細から取込」で個人カードの明細を取り込みます
2. 精算対象の行にチェックを付け（メモ欄の記載がある行は既定でチェック）、支払先を選んで「精算書に追加」します
3. 追加された行は通常の精算明細と同じフロー（保存→承認→起票）で処理されます

## 取り込める形式

* Excel(.xlsx): 列名（日付/内容/出金金額/入金金額/残高/メモ等）を自動名寄せします。「出金金額(円)」のような括弧付き単位も扱えます
* CSV: UTF-8のみ
* 画像(PNG/JPEG): AI（LLM）で読み取ります。AI未設定環境では取り込めません
* カード明細PDF: テキスト層のあるWeb明細の印刷PDFに対応します

## 設定

取り込む銀行・カードの形式差は `config/banks/*.yaml` のプロファイルで調整できます。

```yaml
name: 三井住友カード
type: card                  # bank | card
detect:                     # ヘッダ署名（Excel/CSVの自動判定用）
  - 日付
columns:                    # 列名 → 項目（省略時は既定の名寄せ表）
  date: 取引日
categoryRules:              # 摘要パターン → 区分（省略時は既定ルール）
  - { pattern: '^利息', category: interest }
cardPatterns:               # カードPDF用の正規表現（省略時は既定パターン）
  total: '支払い合計額([\d,]+)円'
paymentAccount: '2030000'   # 引落決済の借方科目（未払金）
paymentSubAccount: 1
interest:                   # 利息仕訳テンプレ（bank種別のみ）
  incomeAccount: '8000000'  # 受取利息
  account: '3730000'        # 源泉所得税の科目（省略時は補助「源泉」から自動解決）
  subAccount: 1
  rate: 0.15315             # 源泉徴収率
```
