# Release Note Ver. 3.0.0

Ver 2.1.0 からの変更（475コミット）をまとめたメジャーリリースです。
「現場で日々使う」ための入力・精算・資金繰りの機能群と、画面構成の整理が中心です。

## 新機能

### 1. 経費精算（立替精算のワークフロー）

- **経費精算書の入力・提出**: 領収書等の証憑を添付して提出すると、承認後に仕訳伝票が起票されます
  - 証憑のまるっとアップロード（未整理証憑パイル）: 複数の証憑を一括アップロードし、後から明細へ割り当て
  - 明細の支払先は「支払先マッピング」、支払資金は「出金元マッピング」で解決（設定画面は証憑種別と同じテーブル構成）
- **立替精算**（会計権限）: 立替者別の精算残高を確認し、精算の伝票を起票します
  - 精算対象科目は立替フラグ付き出金元マッピングから決まります
  - 精算額の符号から精算の向き（返す/もらう）を自動決定します

### 2. 通帳（銀行・カード明細の取込と突合）

- 銀行・カード・計算書の明細を取り込み、仕訳伝票と突合・起票できます
- **計算書伝票ビュー**: 明細行を貸借ペア（借=左/貸=右）で構成し、ドラッグ&ドロップで組み立てます
- **学習ルール**: 取引先/摘要のパターンから相手方仕訳を学習し、次回取込で自動提案します
- 明細複数行を伝票1行へまとめる「グループ化」、グループ構成の学習、
  取り込みの破棄（「なかったこと」）、後着の明細による入金仮の統合にも対応します
- 通帳元帳は承認状態に関係なく明細を表示します

### 3. 付箋・申し送り（Sticky）

- 通知や申し送りを書き、他のユーザーへ通知します（全ページのベルに未読バッジ）
- 種別は「申し送り」（人に伝える）と「メモ」（自分用のTODOメモ）
- 重要度（通常/重要/至急）が設定でき、一覧は未読優先→重要度→新しい順に並びます
- 削除（自分宛のコピー/作者による本体削除）と、受け取った付箋の転送に対応します

### 4. 予定表（資金繰り予定）

- 月々の定常入出金（家賃・給与支払等）と単発の予定を管理します
- **月ビュー（カレンダー）**: 日セルに予定を表示。日セルをクリックすると
  その日の予定登録ができます
- **年ビュー**: 12ヶ月の入金計/出金計/差引と年計を一覧します
- **この月だけ編集**: 繰り返し予定の特定の月だけ、確定した金額に差し替えられます
- **ICSフィード配信**: 予定をGoogleカレンダー等のカレンダーから購読できます
  （トークン付きURL。繰り返しはサーバ側で展開した個別イベントとして配信）

### 5. マイページ（カスタムダッシュボード）

- カスタムメニュー機能を「マイページ」として全ユーザーに開放しました
  （従来は管理者専用で、所有権の保護もありませんでした）
- テンプレート（ホーム/会計メニュー/顧客管理/人事管理/システム管理）から
  作成できます
- **テンプレートとして公開**（管理者）: 自分のマイページを全ユーザーが追加できる
  テンプレートとして公開できます
- ウィジェットはクリックでもドラッグでも追加でき、リサイズハンドルの改善・
  コンテンツのスクロール・フッター固定で操作性を改善しました

### 6. 左メニューの整理

- メニューを業務の流れで6セクション（日々の作業/経費精算/確認・帳票/
  顧客・案件/マスタ/管理）にグループ化しました
- **現在地のグループは常に展開**、他は折りたたみ（見出しhoverで一時表示、
  クリックでピン留め）です
- 「精算」は「立替精算」に改名しました

## 挙動の変更

- **会計年度の自動選択を廃止**: 年度が未選択の状態では「年度を設定してください」
  を表示し、ユーザーに選択を促します（うっかり別年度で作業する事故の防止）
- 年度の確定機能の追加（確定済み年度のデータは強い権限でも変更不可）

## 改善・修正（主なもの）

- 仕訳明細入力をポップアップから専用ページ（/slip）へ移行
- 伝票番号重複で落ちないよう採番を原子化
- 証憑の表示・検索・相手先表示の不具合修正
- 試算表の年度表示500エージェント修正・不明科目の伝票自動承認解除
- 帳票PDFの和文フォントをLinux環境で解決・サーバ側axios自己呼び出しの401クラッシュ修正
- 画面遷移の整理（ルート定義の一元化、タブタイトルの一元解決、ページパラメータ
  の標準化。遷移の検証は nav-smoke.mjs で自動化）
