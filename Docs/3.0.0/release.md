# Release Note Ver. 3.0.0

Ver 2.1.0 からの変更（557コミット）をまとめたメジャーリリースです。
「現場で日々使う」ための入力・精算・資金繰りの機能群と、画面構成の整理が中心です。

## 新機能

### 1. 経費精算（立替精算のワークフロー）

- **経費精算書の入力・提出**: 領収書等の証憑を添付して提出すると、承認後に仕訳伝票が起票されます
  - 証憑のまるっとアップロード（未整理証憑パイル）: 複数の証憑を一括アップロードし、後から明細へ割り当て
  - 明細の支払先は「支払先マッピング」、支払資金は「出金元マッピング」で解決（設定画面は証憑種別と同じテーブル構成）
  - **案件が設定された精算書は「精算書」種別の取引文書として取引管理に現れます**
    （案件・顧客の文書の流れに経費が並ぶ。正は精算書側で、取引管理からは編集不可）
- **立替精算**（会計権限）: 立替者別の精算残高を確認し、精算の伝票を起票します
  - 精算対象科目は立替フラグ付き出金元マッピングから決まります
  - 精算額の符号から精算の向き（返す/もらう）を自動決定します

### 2. 通帳（銀行・カード明細の取込と突合）

- 銀行・カード・計算書の明細を取り込み、仕訳伝票と突合・起票できます
- **計算書伝票ビュー**: 明細行を貸借ペア（借=左/貸=右）で構成し、ドラッグ&ドロップで組み立てます
- **学習ルール**: 取引先/摘要のパターンから相手方仕訳を学習し、次回取込で自動提案します
  - 起票時に**使用したルールをその場で提示**します（隠れたルールはありません）
- 明細複数行を伝票1行へまとめる「グループ化」、グループ構成の学習、
  取り込みの破棄（「なかったこと」）、後着の明細による入金仮の統合にも対応します
- **合流**: 手数料・税など付随する行は主取引（振込等）の伝票に合流します。
  合流先がないときは単独の伝票を立てず、直前の未照合の主取引と一緒に起票します。
  利息の源泉（国税等）もルールの科目で起票します
- 取込行の状態（仮起票/起票済）から**伝票ページへ直接リンク**します。
  通帳（銀行）の明細行からも直接起票できます
- 計算書: 相手の入金行が未照合でも、その場で起票してから統合します
  （手動統合でも同じ）。**「起票をやめる」**で取り消せます。
  伝票日付はその場で変更できます。仕訳パネルには読み取り・照合・下書きの
  層別の状態を表示します。テキスト層のないPDF（Amazon支払明細書）にも対応します
- 通帳元帳は承認状態に関係なく明細を表示します

### 3. 付箋・申し送り（Sticky）

- 通知や申し送りを書き、他のユーザーへ通知します（全ページのベルに未読バッジ）
- 種別は「申し送り」（人に伝える）と「メモ」（自分用のTODOメモ）
- 重要度（通常/重要/至急）が設定でき、一覧は未読優先→重要度→新しい順に並びます
- 削除（自分宛のコピー/作者による本体削除）と、受け取った付箋の転送に対応します

### 4. 予定表（資金繰り予定）

- 月々の定常入出金（家賃・給与支払等）と単発の予定を管理します
- **月ビュー（カレンダー）**: 日セルに予定を表示。日セルをクリックすると
  その日の予定登録ができます
- **年ビュー**: 12ヶ月の入金計/出金計/差引と年計を一覧します
- **この月だけ編集**: 繰り返し予定の特定の月だけ、確定した金額に差し替えられます
- **ICSフィード配信**: 予定をGoogleカレンダー等のカレンダーから購読できます
  （トークン付きURL。繰り返しはサーバ側で展開した個別イベントとして配信）

### 5. マイページ（カスタムダッシュボード）

- カスタムメニュー機能を「マイページ」として全ユーザーに開放しました
  （従来は管理者専用で、所有権の保護もありませんでした）
- テンプレート（ホーム/会計メニュー/顧客管理/人事管理/システム管理）から
  作成できます
- **テンプレートとして公開**（管理者）: 自分のマイページを全ユーザーが追加できる
  テンプレートとして公開できます
- ウィジェットはクリックでもドラッグでも追加でき、リサイズハンドルの改善・
  コンテンツのスクロール・フッター固定で操作性を改善しました

### 6. 左メニューの整理

- メニューを業務の流れで6セクション（日々の作業/経費精算/確認・帳票/
  顧客・案件/マスタ/管理）にグループ化しました
- **現在地のグループは常に展開**、他は折りたたみです
- 見出しにhoverすると**右横にフライアウト**で子項目が出ます（下の項目は
  動きません）。孫メニューも同じくhoverで右横に展開します
- 見出しをクリックすると常時展開を固定できます（もう一度クリックで解除）
- 「精算」は「立替精算」に改名しました

## 挙動の変更

- **会計年度の自動選択を廃止**: 年度が未選択の状態では「年度を設定してください」
  を表示し、ユーザーに選択を促します（うっかり別年度で作業する事故の防止）
- 年度の確定機能の追加（確定済み年度のデータは強い権限でも変更不可）
- **APIの権限を完全化**: 約230エンドポイントを棚卸しし、許可表とhandlerの
  絞り込みを整備しました
  - 伝票の新規作成（API）は会計・承認権限に限定（従来はログイン済みなら
    誰でも未承認伝票を作成できました）
  - 証憑の一覧・取得は本人が作成したものか会計権限に限定しました
  - 他人の証憑へのファイル添付・bind・ファイル削除・OCRの起動を拒否します
  - **承認済みの精算書・伝票に載った証憑は、作成者でも会計権限でも変更・削除
    できません**（承認を戻せる承認権限のみ操作できます）
  - **人事閲覧権限（personnelBrowsing）を追加**: 人事情報を参照のみ行う
    役割（経理デスク等）のための閲覧専用権限です。人事管理権限は読み書き
    セットなので、参照だけの役割には付けられませんでした。
    役職員一覧・ユーザー情報の参照に使えます（人事の操作は不可）
  - 出金仮統合の2API（マージ候補・実行）を許可表に登録しました
    （未登録のため誰にも403になる壊れた機能になっていました）
  - 起動時に許可表へ未登録のAPIを検知するlintを追加しました

## AI連携

- **AI管理権限とプロンプトの世代管理**: プロンプトの管理のための独立した権限
  （aiManage）を追加しました。OCR・仕訳等のプロンプトをDBに「用途×世代」で
  保存し、専用の「AI設定」ページで管理します
  - 履歴の一覧（どの世代が有効か、説明付きで表示）
  - 過去世代への切り替え（**「この世代を使用」**）
  - 世代ごとの**説明**（メモ）の編集と**削除**
  - 「リセット」で配布時の内容に戻せます。変更はAI処理へ即座に反映されます
- 管理者ホームにAI設定パネルを追加（config/llms.yaml をUIから編集。
  モデルはカタログから選択: Gemini 3.5 Flash Lite / Gemini 3.5 Flash /
  **Gemma 4 31B（低コスト・画像PDF対応・実運用実績あり）** /
  GPT-5.4 mini / GPT-5.4（OpenAI・要APIキー） /
  muse-spark / 手動設定）
- voucher-mcp の応答から添付本文（files[].body）を除外
- 証憑の複数文書切り出し（extract_document）に対応

## 運用上の注意

- DBの**マイグレーション**が必要です（`npx sequelize-cli db:migrate`）
- **aiManage権限は既定では付与されません**。必要なユーザーにユーザー編集で
  付与してください（人事閲覧権限も同様）
- **管理権限のみのユーザーは役職員マスタを直接操作できなくなりました**
  （人事管理権限・人事閲覧権が必要です。ユーザー権限の操作と人事の個別
  操作の分離）
- Docker利用時はイメージの再ビルドが必要です（ベースを node:24 に更新）
