# 2026-11-19〜20: 通帳取り込み周りの修正と AI管理/プロンプト世代管理

（作業の詳細は Docs/logs/20261116.md の該当節に逐次記録してある。ここは日次サマリ）

## 主な修正

- **計算書の学習済みレイアウト**（settleLayout）: 同名行の照合を(摘要, 向き, 出現順)で
  行うように。統合型学習（使わない月に一度でも出なかった行を消さない）。
  旧書式レイアウトの曖昧照合（同名行が両向きに出たら照合しない）。
  seedの二重割付と「空白違いラベルの重複」も解消
- **計算書の起票/取り消し**: 「起票をやめる」(unsettle) を追加。統合候補が無いとき
  同額±3日の未照合入金行を起票して統合。ルールで直接起票された1行伝票も
  統合先にする。突合で1行伝票から計算書側伝票へ紐付け替え
- **通帳取込行に伝票直リンク（crossSlipId）**: 明細リンクは保存時の明細の
  作り直しで切れるため、「完成させた保存で未照合に戻る」問題を根本解決
- **元帳**: 科目選択後の表示切替が遅れる問題をSSOT原則（URL直接読み）で修正
- **科目入力**: 候補selectの矢印キーによる勝手な確定を禁止（全用途・account.svelte共有）
- **計算書仕訳パネルに状態表示**（読み取り検算○✗ / レイアウト照合率 / 下書きの由来）

## AI管理権限とプロンプトの世代管理（新機能）

- 新権限 `aiManage`: プロンプトの世代管理（AI設定ページ）とAI設定（llms群）を操作できる。
  ユーザ管理にチェックボックス列。homeのAI設定パネルをadministrable→aiManageに
- `PromptTemplateVersions` テーブルで用途ごとに世代保存（現世代=最大generation）。
  保存/ロールバック/リセットは全て新世代として積む（履歴不滅）。世代に「説明」付き、
  世代の「削除」可（現世代削除で残った最大世代が繰り上がり、全消滅でビルトインに戻る）
- manifest-engine は無改修: 現行本文を `runtime/prompt-templates/` にマテリアライズして
  TEMPLATE_DIR から供給（libs/ai-prompts.js 新設。ai/host/index.js が起動時に反映）
- 管理セクションに「AI設定」ページ（用途一覧・エディタ・ビルトイン比較・履歴）。
  動作確認ループは「編集 → 通帳一覧の取込プレビュー」
