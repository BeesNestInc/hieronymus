# 2026-11-09: SPA の `<TITLE>` を画面に合わせて切り替える

## 要望

- 画面全体がSPAのため `<TITLE>` が変わらず、タブの区別が付かなくて不便
- 方針: 詳細表示に拘らず「区別が付けばよい」。
  `<TITLE>` のためにDBを読むことはしない。表示する項目の中から流用する
- 形式は会社名入り（`ページ名 [詳細] - 会社名::Hieronymus`）

## 調査

- 画面遷移は `front/javascripts/router.js` の `currentPage` store +
  `pushState`。表示コンポーネントの解決は
  `front/svelte/index.svelte:84-165` の `routes` 配列 +
  `front/svelte/components/router.svelte`
- `document.title` の更新はどこにも無かった（`grep document.title` で0件）。
  サーバは `views/index.spy:4` の `<title>{{title}}::Hieronymus</title>` を
  初回ロード時に返すだけで、SPA内遷移では不変
- 詳細IDはURLに既出（例 `slip-page.svelte:291-318 parsePage` が
  `/slip/new?year=&month=` と `/slip/:year/:month/:no` をURLだけで判別、
  `voucher.svelte:150-156` 等も `args[2]` だけで `list/new/entry` 判別）。
  会社名は `index.svelte:205 getCompanyInfo()` の取得済み値を流用できる
- ログイン系はSPA外の別バンドル（`login.js` + `login.svelte` +
  `views/login.spy`）。対象外だが固定文言だけ付けることにした

## 実装（commit acdc7ee、4ファイル、+177/-1）

- 新規 `front/javascripts/title.js`
  * 画面基底名マップ22種（各画面の `<h1>` に合わせる。
    通帳だけ一覧/詳細で基底名を変える: 通帳一覧/通帳）
  * URL断片だけの詳細（区別用。DB読みなし）。
    例: `/slip/2024/5/12`→`2024/5-12`、
    `/slip/new?year=2024&month=5`→`新規 2024年5月`、
    `/voucher/entry/123`→`123`、`/journal/2024/5`→`2024年5月`、
    一覧/新規の判別
  * 形式 `${base}${detail} - ${companyName}::Hieronymus`
    （会社名・詳細が無ければ省略）
  * `pageTitleDetail` writable store:
    表示用取得済み値の上書き受け口（タイトル用新規fetch禁止の規約）
- `front/svelte/index.svelte`
  * `$: docTitle = buildTitle($currentPage, status.company?.name, $pageTitleDetail);`
    `$: if (document && docTitle) { document.title = docTitle; }`
    （既存の modal 用 `title` 変数と衝突しないよう `docTitle` 名義）。
    戻る/進む・深リンク直開きも `currentPage` 経由で自動追従
- `front/svelte/menu/menu.svelte`
  * 表示用取得済みの `menu.title` を `$: pageTitleDetail.set(menu?.title || null);`
    で流用。`onDestroy` でクリア。非menu画面では上書きを無視する
    （`buildTitle` 側で `/menu` 以外は `detailOverride` を使わない）
- `front/svelte/login.svelte`
  * `ログイン::Hieronymus` / `アカウント登録::Hieronymus` を直接設定
    （会社名はログイン前なので付けない）
