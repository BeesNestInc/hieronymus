明細に手入力済みの金額が 0 で上書きされて消えていた。

- `front/svelte/cross-slip/cross-slip.svelte` の `bindVoucher` を修正。
  `voucher.amount != null && numeric(voucher.amount) !== 0` の場合のみ
  `debitAmount` / `creditAmount` を更新・フォーマットするようにした。
  証憑紐付け（VoucherId・税・会社名）は従来通り行う。
  金額が `0` / `"0"` / `""` / `null` / `undefined` のときは明細金額に触れない。
