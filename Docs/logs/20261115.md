# 2026-11-15 作業ログ

## 管理者ホームに「AI設定」パネルを追加

### 簡素化（モデル選択リスト化）（6fc24b4 の次）

ユーザー指示で「モデルやプロバイダはリストから選択」に簡素化:

- **`ai/host/model-catalog.js`**（新規）: 選択肢カタログ。text/image/pdf 受容・
  構造化出力対応の「十分な機能を持つモデル」だけを並べる（現行: Gemini 3.5
  Flash Lite / Gemini 2.0 Flash / muse-spark ゲートウェイ / 手動設定）。
  カタログ外は `manual` エントリ経由で従来の詳細フォームに降りる
- **パネルUI**: 「モデル（ラジオリスト）＋APIキー」だけ。accepts や
  structuredOutput は非表示（カタログが吸収）。manual 選択時だけ詳細フォーム
  （プロバイダ/モデル名/baseURL/accepts/structuredOutput）を出す
- **保存時のキー引き継ぎ改善**: プロバイダが替わる保存で apiKey 未入力なら
  旧プロバイダのキーを引きずらない（`dropExistingKey` 内部フラグ）。
  同一プロバイダ内のモデル変更では従来通り維持
- `GET /admin/llms` が `catalog`（表示用: key/label/note/manual）と
  `catalogKey`（現在の先頭候補と一致するカタログキー、カタログ外は manual）を返す

### 背景

AI（LLM）の設定は `config/llms.yaml` を直接手編集するしかなく、
APIキーを含むため 운用上つらい。管理者ホームの既存パネル
（`config/company.json` をUIから編集する SystemSettings と同じ構図）として
AI設定パネルを追加した。

### 実装

- **`ai/host/model-provider.js`** に書き込み側を追加:
  - `standardCandidateInfo()`: `llms.standard` 群の先頭候補をパネル表示用に返す。
    apiKey はマスク（先頭4文字+`***`）して生キーをブラウザへ渡さない。
    `available`（isAvailable()）と環境変数上書き検出（LLM_*）も返す
  - `validateStandardCandidate(patch, existing)`: provider 5種限定・model必須・
    gemini/openai は apiKey 必須・それ以外は baseURL 必須（makeModel の挙動に揃える）。
    existing を渡すと「空欄 = 既存キー維持」をキー要件の判定に使う
  - `updateStandardCandidate(patch)`: standard 群の**先頭オブジェクトだけ**を
    差し替えて yaml に書き戻す（文字列参照・後続候補・他群は保持）。
    空欄 apiKey は既存キー維持、structuredOutput は false のときだけ書く
    （未書き = true）。yamlダンプでコメントが消えるためヘッダは毎回再生成。
    保存後 `validateLlmsNames()` を実行し重複名を warnings として返す
    （**model-provider.js:117 の「Phase 3 で結線」残留タスクがここで完了**）
  - `configPath()` を公開し、読み書きが同じパスを見るように
    （テストは LLM_CONFIG_PATH で隔離される）
- **`routes/api_admin.js`**: `llmsGet`/`llmsPut` を追加（AI SDK ロードを起動経路に
  広げないため動的import — api_user.js の vision と同じパターン）。
  バリデーションエラーは 422
- **`routes/api.js`**: `GET/PUT /admin/llms` を登録。権限は既存の
  `/admin → administrable` ルール（libs/permission.js:145）で追加不要
- **`front/svelte/home/ai-settings.svelte`**（新規）: system-settings.svelte の
  カードパターンを踏襲。provider ドロップダウン、model/apiKey(password)/baseURL、
  accepts チェックボックス、structuredOutput スイッチ。apiKey はマスク値を
  プレースホルダ表示。環境変数上書き検出時は警告バナー
- **`front/svelte/home/home.svelte`**: 管理者限定行にパネルを追加。
  AI未設定メッセージの案内を「config/llms.yaml 直接編集」→「管理者ホームの
  AI設定パネル」に変更

### 判断

- 編集対象は standard 群の先頭候補のみ（ユーザー確認済み）。
  複数候補・フォールバック・alternate 等は引き続き手編集
- 保存先は `config/llms.yaml` のまま。`loadConfig()` が毎回再読込するため
  保存は即時反映（再起動不要）。モデルキャッシュはキャッシュキーに設定値を
  含むため apiKey/model 変更時は新しいモデルが作られる
- DBへの移行はしない（ファイルが実質の単一ソースであり、移行メリットが薄い）

### 検証

- `npx mocha test/ai-host.test.js`: 10件合格（保存系5件を追加。テストは
  フィクスチャを /tmp にコピーして LLM_CONFIG_PATH で指すため実ファイル不 touch）
- `npm run build` 成功

  （`candidates()` は model を返さない / フィクスチャの alternate 群にも

- `config/llms.yaml` には生キーがあるが `.gitignore:75` 済み
