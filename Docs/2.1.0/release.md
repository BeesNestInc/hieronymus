# Release Note Ver. 2.1.0

## 新機能

### 1. AI連携（伝票入力の自動化）

本バージョンでは、AIエージェント（Claude Code / opencode 等）から会計データを操作するための統合基盤を追加しました。リポジトリ直下の `ai/` ディレクトリに、スキルとMCPサーバを配置しています。

- **伝票入力MCP（`ai/mcp/voucher-mcp/`）**
  - 仕訳伝票・証憑の作成、更新、承認、削除をツールとして提供します。
  - 勘定科目・取引先・税率・会計年度などのマスタ参照にも対応します。
- **経理スキル（`ai/skills/`）**
  - `voucher-entry`: 証憑（画像/PDF）の読み取りから証憑登録・自動仕訳（承認待ち）までをガイドします。
  - `journal-learning`: 過去の仕訳日記帳から仕分けパターンを学習し、Wiki上のパターンページを保守します。

### 2. 証憑のOCR（画像/PDF）読み取り

- 証憑の画像・PDFをAIで読み取り、会社名・金額・日付・税率・請求番号などを抽出できます。
- PDFは1ページ目を自動で画像化して処理します。
- 使用するAIモデルは設定（`config.llms`）で変更可能です（既定: MiMo、Gemini 等への切替可）。

### 3. 自動仕訳の学習基盤

- 過去の承認済み仕訳から「取引先/摘要 → 借方・貸方」の仕分けパターンを学習し、新しい証憑を自動で仕訳します。
- 仕分けパターンは Wiki（Markdown）で管理するため、**人間が直接確認・修正できます**。
- パターンにない新規ケースは自動仕訳せず、人間に確認を求めます。
- 承認は人間が行います（AIは承認しません）。

### 4. 税額計算のサーバ権威化

- 従来クライアント側（ブラウザ）で計算していた税額を、**サーバ側で再計算・検証**するようにしました。
- 借方と貸方の合計不一致、未登録の勘定科目、不正な税率はサーバ側で拒否されます（HTTP 422）。
- 仕訳伝票・証憑の両方に適用されます。

## 修正されたバグ

### 1. APIの認証・認可の欠落（セキュリティ）

- 従来、API（`/api/*`）の多くが認証・権限チェックなしでアクセス可能でした。
- 全APIを認証必須とし、画面ごとのロール（会計 / 決算閲覧 / 承認 / 会社管理 / 管理者 等）に応じた権限チェックを一括適用しました。
- 未認証は401、権限不足は403を返します。
- これに伴い、非会計ユーザーが「伝票・証憑の作成」を行えるワークフローを追加しました（作成した伝票は承認待ちになります）。
